FSM

Velg FSM-server

Skriv inn adressen til FSM-plattformen. Adressen lagres på denne enheten og brukes neste gang appen åpnes. Den er ikke bygget inn i appen.

Lagret server

Offline: Data du har åpnet, lagres i minst 7 dager slik at appen kan brukes uten nett. Logg ut eller bytt server for å slette lokal data. Bruk alltid HTTPS i produksjon.

Trenger du hjelp?

Adressen er den samme som du bruker i nettleseren, for eksempel https://felt.firma.no. For lokal testing kan du bruke http://10.0.2.2:3000 på Android-emulatoren eller http://localhost:3000 på iOS-simulatoren.

Hvis serveren ikke svarer, kontroller at telefonen er på nett og at adressen peker til en kjørende FSM-installasjon med gyldig sertifikat.
